I started as a software engineer, but I kept noticing things engineers aren't supposed to notice — broken processes nobody questioned, data that told a different story than everyone assumed, workflows that turned out to be people problems wearing a technical costume.

Eventually, the question behind the code mattered more than the code itself. That realization led me to Arizona State University's W. P. Carey School of Business, a 4.0 GPA, and a capstone that won the Outstanding Capstone Team Award.
